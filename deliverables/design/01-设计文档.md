## 1. TL;DR

1. **根本问题不是「不好看」，是品牌、事实、审美三条线同时脱节**。官网是暖纸白 + 森林绿的手稿星图，产品是深蓝黑 + 极光蓝紫的桌面原生工具；官网写着「3D 知识图谱 / AI 知识库 / 不发起任何联网请求」，产品源码明确「2D SVG 4 布局 / 无 AI / 有 opt-in 遥测与博客部署」。
2. **模式判定：Redesign-Overhaul**。视觉按 greenfield 强度重组，内容 / IA / SEO 按 overhaul 保护存量契约。品牌没换，不判 greenfield。
3. **IA 定稿为 11 区块、9 个旧锚点零迁移**。不新建章节锚点、不做兼容锚点、无 301 表。Filler 的病因在内容而非骨架：保留区块，把抽象散文换成可核实规格。
4. **视觉统一到产品 §18 桌面原生语言**，按 landing 语境做分层密度适配；继承色板 / 字体 / 圆角 / 动效纪律，不继承 IDE 紧凑 chrome。
5. **本轮最重要的一条**：把 4 处事实错误改对，比任何视觉改动都优先。一个主打数据主权的产品，不能在自己最强的章节上说不真实的话。

## 2. 三条断裂（重设计依据）

### 2.1 品牌断裂

| 维度 | 产品本体 | 官网现状 |
|---|---|---|
| 背景 | `#0D0F15` / `#101218` / `#151821` | `#f3f0e8` 暖纸白 / `#171915` 夜书房 |
| 主色 | `#7C8CFF` 极光蓝紫（`-mc-accent`） | `#3f6b47` 森林绿 |
| 字体 | Inter 系统原生栈 + 语义字号 | Noto Sans SC + 拉丁衬线展示标题 |
| 节奏 | 8px 网格、发丝分隔、高密度 | 最大 9rem 留白、手稿卡片 |
| 动效 | <300ms、仅 transform / opacity、频率门控 | 180 / 320 / 620ms，含 ease-in-out |
| logo | 蓝紫方块 M | favicon 深墨绿方块 + 星点连线 |

产品本体已有一份由**本次用户指定的同样三套 skill** 提炼出的《桌面原生设计基线 §18》，并完成多轮 UI 重构；官网是唯一没纳入该体系的界面。

### 2.2 事实断裂（4 处必须校准）

| 位置 | 现有断言 | 核实结论 |
|---|---|---|
| `index.html` description | 「3D 知识图谱」「AI 知识库」 | 图谱是 SVG 2D 四布局；3D 球体 / PageRank / 社区聚类从未实现；无 AI / LLM，检索是本地统计（关键词重叠 + 词频摘句） |
| `FaqSection.tsx:20` | 「当前版本没有任何需要联网的功能」 | 博客部署、外部 URL 导入、图床上传、可选匿名统计均联网 |
| `FaqSection.tsx:24` | 「不发起任何联网请求」 | 同上，属过度承诺 |
| `LocalSection.tsx:22` | 「不发起任何联网请求」 | 同上 |

**不能误改的部分**：官网关于「笔记正文是 Vault 文件夹里真实 `.md` 文件、可用网盘 / Git 同步、整库带走」的断言**属实**。产品 `src/core/data/defaultDocs/zh.ts` 帮助原文明确：笔记正文 = 用户 Vault 的真实 `.md`；应用状态（笔记树 / 知识库 / 白板 / 版本历史）= JSON 存 `%APPDATA%\MarkCraft\storage\`；设置 / 主题 = localStorage；默认每 30 秒自动保存 + 500ms 防抖 + 崩溃恢复。这是最有说服力的信任章节，必须保留并讲得更精确。

### 2.3 审美错位

产品 `docs/Markcraft_重新设计_DesignBrief.md` 记录了用户的真实决策史：多轮否掉企业后台 / B 端控制台风（统计卡 + 图表 + 密集表格）、否掉写作 / 文档 / 笔记隐喻的首页、否掉「不够差异化」的常规方案；最终认可的 L1 Launchpad v2 是视觉锚点 + 左大右小非对称 + 中性启动器；编辑器方向选 VS Code 式活动栏（IDE 感、高密度、键盘优先）。

**现官网恰恰建立在被否掉的「手稿 × 星图」写作隐喻轴上。**

> 来源澄清（重要）：「首页完全不谈写作 / 文档 / 笔记」出自 DesignBrief 的 **in-app Launchpad** 决策（该产品内首页范围见 `Markcraft_重新设计_DesignBrief.md:1-4`，决策见 :90），**不是本次用户明确指令**。本次只把它作为官网视觉语言的参考方向，列为可复议的待确认假设，不写作「用户已拍板」。

## 3. 现状审计结论

### 3.1 九节做功判定

| 章节 | 判定 | 处置 |
|---|---|---|
| Hero `#top` | 半做功 | 骨架有效（品牌锚点 + 双 CTA），但 H1 是抽象英文 tagline、3 秒说不清品类；「体验 Demo」指向 `#craft` 但全站无 Demo 实体（假 affordance） |
| Workflow `#statement` | 内容 filler | 「记录 / 连接 / 创作」三阶段零产品事实。**保留区块**，三格改填「导入 / 连接 / 发布」真实规格 |
| Craft `#craft` | 做功，必须保留模式 | 同一份 Markdown 的源码 / 渲染并置，是全站唯一「用产品自证产品」的结构；补真实技术名（CodeMirror 6 / Tiptap 3 / GFM） |
| Connection `#connection` | 做功，事实欠精准 | 双链 / 反链 / 图谱属实，但需明确「SVG 2D 四布局」并与已删的 3D 宣传切割 |
| Possibility `#possibility` | 内容 filler | 4 条通用散文，其中「摘录式回答」最易被读成 AI。**保留区块**，三行改填白板 / 知识库 / 命令面板真实规格 |
| Output `#output` | 强做功，必须保留模式 | 63 主题真实配色小样 + 12 格式逐条 + 「样本非全集」标注，是全站可核实文案范本；补上官网缺失的部署能力 |
| Local `#local` | 做功，含 1 处致命错误 | 本地优先独立成节正确；`.md` / Vault / 同步 / 带走断言全部属实；只需改「不发起任何联网请求」并补 opt-in 统计说明 |
| FAQ `#faq` | 做功，含 2 处错误 | 原生 `<details>` 是无障碍优势必须保留；平台声明与导出格式列表诚实准确；改 2 处联网断言，6 条增至 8 条 |
| Download `#download` | 骨架做功，路径断裂 | 「不编造」纪律（空值不展示、`hasDirectDownloadLink:false`）必须保留；但「clone 后合并」这个最高摩擦事实被外包给第三方 README，页面内没讲清 |

**结论：9 节里 6 节做功、1 节半失效、2 节内容 filler。改法不是全部推翻，而是「保留骨架 + 换掉抽象内容 + 重做 Hero 承诺 + 重做下载路径 + 校准 4 处事实」。**

### 3.2 必须保留的模式

配置驱动 + 单一数据源（`siteConfig.nav` 顶导 / 页脚共用，`downloadConfig` 集中下载信息，数据文件带主仓出处注释）；「不编造」纪律（未核实字段保持空、样本标注非全集、未发布能力不宣传）；诚实的平台声明；本地优先独立成节及 `.md` / Vault 断言；FAQ 原生 `<details>`；语义化标签与唯一 `<h1>`；Craft 同源并置自证；Output 真实主题配色小样。

### 3.3 必须退役的模式

「体验 Demo」假 affordance；Workflow / Possibility 的抽象散文；3D / AI 一切夸大与视觉意象；两处「不联网」绝对化断言；`≤768px` 直接 `display:none` 且无替代；外部链接无 `target` / `rel`；死代码（`Container.tone`、`siteConfig.nav[].label`）；旧 favicon 与产品 M 标不一致；旧色板 / 1180px / 9rem / 620ms；未标注的虚构示例文章；页脚缺隐私政策链接与 skip link。

### 3.4 SEO 基线判断

现状只有 `<title>` + description（且含 2 个虚假功能词）+ favicon + `lang="zh-CN"`，**无 OG / Twitter / canonical / robots / sitemap / 结构化数据 / 分享图 / noscript 摘要**。基线几乎为零，因此排名流失风险低、错误摘要修正收益高。本次按「一次性把契约定死 + 补齐」处理，不做保守保全。

### 6.2 文案纪律（全站强制）

- **禁词**：3D、AI、智能、赋能、无缝、下一代、革命、重新定义、一键、立即下载、体验 Demo、手稿、星图、纸、书房、写作 / 文档 / 笔记（作为文学化隐喻时）；Elevate / Seamless / Unleash / Next-Gen / Game-changer / Delve / Tapestry。
- **不禁**：Markdown、知识库、`.md` 文件、双向链接、知识图谱、白板、发布、导出等精确技术名词。
- **禁手法**：em-dash / en-dash 装饰、感叹号、虚构评价 / 下载量 / 评分 / 背书 / 性能数字 / 案例、把关键文案只画进图片或 SVG、Step 编号、eyebrow。
- **强制**：每个功能断言能指回主仓一个文件或常量；数字标注来源且标注「样本非全集」；未定项（发布日期、最低系统版本、校验和、具体版本号、价格）一律不写；0 eyebrow；区块标题 ≤8 词；Hero 恰好 4 个文本元素；全站恰好 3 处 CTA。

### 6.3 元数据定稿口径

- `<title>`：品牌 + 品类 + 形态 + 平台 + 差异，约 30 字，零夸大。允许「笔记」等检索词。
- `<meta description>`：每项可核实，用「2D」正面反掉旧的 3D，用「核心功能离线可用」替代绝对化「不联网」，用「无云端账号」而非「没有云端」。允许「笔记」等检索词。
- `og:title` / `og:description` / `og:image:alt`：与视觉层一致，0 禁词，与 `<title>` 同一事实源。

逐区块成品文案与元数据定稿见 `04-文案定稿.md` 与效果图 `index.html`。

## 7. SEO 迁移契约

### 7.1 必须保持稳定（改版不得动）

| 类别 | 稳定项 |
|---|---|
| URL | 单页 `/`，`base:'./'`，不新增路径、不改 hash 策略、不引入路由 |
| 锚点 id | 9 个全部原样保留（见 §5） |
| 导航中文标签 | 沿用旧可见标签，只补 1 项；不得静默改名 |
| 单一数据源 | `siteConfig.nav` 顶导 / 页脚共用 |
| 语义 / 无障碍 | `lang="zh-CN"`、语义标签、唯一 `<h1>`、FAQ 原生 `<details>`、焦点环，不得回退 |
| 外链目标 | 源码仓库、安装包仓库、guideUrl 的 `#下载与合并` 不变，只补 `target` / `rel` |
| 法律 / 品牌 | 站点名 MarkCraft、版权起始年份 2026 不变；favicon 与 logo 变更须显式拍板 |

### 7.2 需补齐

- **Meta 基础**：`<title>` / description 换成校准后文案；`<link rel="canonical">`（域名确定后）；`robots.txt` + 最小 `sitemap.xml`（仅含 `/`）；`<meta name="theme-color">`；保持 favicon 路径。
- **Open Graph**：`og:type=website` / `og:site_name` / `og:title` / `og:description` / `og:url` / `og:image` / `og:image:alt` / `og:locale=zh_CN`。
- **Twitter**：`twitter:card=summary_large_image` / `twitter:title` / `twitter:description` / `twitter:image` / `twitter:image:alt`。**无官方账号则不写 `twitter:site/creator`**。
- **分享图**：`1200×630`（1.91:1），PNG / JPG，< 1 MB；另备 `1200×1200`。四周 64-80px 安全区；关键文案不得只画在图里；视觉走新深色 `#101218` + `#7C8CFF`；禁 3D 球体 / 紫辉光 / 虚构数字 / 未发布平台字样。
- **结构化数据**：只写 `WebSite` + `SoftwareApplication` 的可核实字段（`name` / `applicationCategory=DesktopApplication` / `operatingSystem=Windows` / `description` / `url` / `author`）。**省略** `softwareVersion`（版本未对齐）、`releaseDate`（空）、`downloadUrl`（无直链）、`offers`（无价格）。**禁止** `aggregateRating` / `review` / 虚构评论。`FAQPage` 首期不加，待文案定稿后再补。
- **SPA 可抓取性**：正文全在 JS 里，把真实产品摘要静态写进 `index.html` 并提供 `<noscript>` 摘要；保持语义化标题；关键文案不进图片 / SVG / canvas。
- **无障碍不回退**：`<details>` FAQ、可见焦点环、skip-to-content、占位框 `aria-label`、`prefers-reduced-motion`、移动端保留全部内链、外链 `rel="noopener noreferrer"`。

### 7.3 风险与缓解

| 风险 | 缓解 |
|---|---|
| 错误 description（3D / AI）已被缓存 | 上线首日同步更新 title / description / OG；必要时提交重新抓取 |
| 退役内容锚点失效 | 9 个锚点全部保留，零迁移 |
| 「体验 Demo」删除后旧物料落差 | 统一改「了解功能」→ `#statement`，并补强 B3 真实规格 |
| SPA 无 SSR 正文抓不到 | 静态摘要 + `<noscript>`；关键文案不进图 |
| 版本号未对齐却写 `softwareVersion` | 对齐前省略该字段 |
| H1 换成纯图形 / 英文 tagline | H1 保留品类直陈文本 |
| 移动端继续隐藏导航 | 两行文字网格常驻全部链接 |
| 结构化数据写 downloadUrl / 评分 / 评论 | 只写可核实字段 |
