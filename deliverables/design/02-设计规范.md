## 0. 一句话结论

官网是产品桌面原生语言的公开面：同一套深色近黑底、发丝分隔、极光蓝紫单 accent、Inter 系统原生栈、4/8/12 三档圆角与 8px 网格；把 IDE 的紧凑密度**在区块之间松开、在区块之内保留**，用左大右小的非对称启动台骨架组织信息，以产品视图示意占位框（纯色标注，不画假界面）作为视觉锚点之一。零写作隐喻、零卡片堆砌、零自动入场动画。

## 1. Design Read 与三档拨盘

**Design Read**
> Reading this as: 桌面原生软件的**全量视觉重设计官网**（redesign - overhaul / greenfield visuals）for 正在评估下载、对模板化界面敏感的设计意识型桌面用户，with a **深色桌面原生 · 工具感 · 非对称启动台**语言，leaning toward 产品 `--mc-*` 令牌体系 + React 18 / Vite 5 原生 CSS + 零动画库的克制交互。

| 拨盘 | 值 | 依据 |
|---|---|---|
| `DESIGN_VARIANCE` | **4** | 用户 L1 v2 要「打破工整、左大右小非对称」，不能取 1-3；但 taste §7 的 8-10 档靠 `padding-left:20vw` 大空白实现，与 §18 §11 反大留白冲突。取 4-7 Offset 档下沿：非对称只用 7fr:5fr 栅格 + 32px 纵向偏移 + 48px 负 margin bleed，不靠空白。 |
| `MOTION_INTENSITY` | **2** | §18 §7.1 频率门控、§11「<300ms / 键盘高频不动画」、工具型产品人格（review-animations 标准 10 cohesion）。taste §7 的 1-3 Static 档 = 无自动动画，仅 hover / active / focus。滚动淡入是最典型的模板 signature。 |

## 2. 设计语言定义与边界

### 2.1 继承 §18（不可破）

色值全走语义 token 且单来源；`--mc-accent #7C8CFF` 唯一品牌色、其外之紫全禁；字体系统原生栈 + 语义字号纪律（不裸写 font-size 的精神）；8px 间距基准；圆角三档单来源 4 / 8 / 12 + pill 仅小标签；发丝 1px 分隔；扁平暗色、无玻璃、无辉光、无渐变；线性描边图标、禁 emoji；UI 动效 <300ms、ease-out、仅 transform / opacity、禁 ease-in / `transition: all` / `scale(0)`；键盘可达 + 图标 aria-label；reduced-motion / reduced-transparency / increase contrast；无假 affordance、单主入口、无 FAB / 无汉堡 / 无自定义窗口 chrome。

### 2.2 按 landing 语境适配

| 适配项 | 官网值 | 产品值 | 理由 |
|---|---|---|---|
| 语义字号阶梯 | 新建 `--web-*`（H1 clamp 40-72px） | `--mc-font-*` 11-34px | 官网是 1.5-3m 阅读距离 + 首屏传达，需大 3-5 倍。另建前缀，不污染产品 tokens.css。 |
| 区块垂直内距 | 96px / 128px / 移动 64px | 16-24px 组间距 | landing 需要滚动节奏；远低于旧官网 9rem (144px) 与 taste art-gallery 的 128-192px。 |
| 容器与栅格 | 1200px / 12 列 / gutter 24px | 固定侧栏 200px + inspector 280px | Web 视口可变，需 max-width 约束与列式组织。 |
| 主 CTA | 全站恰好 3 处 CTA（nav / Hero / Download），accent 实底按钮 52px 高 | IDE 内主动作进工具栏 | landing 需单一转化焦点；§8.4 单主入口仍守。Download 主按钮是全站唯一**外部仓库入口**，不是文件直链（见 §5.6）。 |
| 小字色 | 新增 `--web-text-muted #8A93A6`（6.1:1） | `--mc-text-tertiary #6B7280`（3.9:1） | landing 小字承载信息更多，3.9:1 不达 AA 4.5:1。 |
| accent 实底按钮文字 | `#0A0B0F`（6.6:1） | `--mc-text-inverse #FFFFFF`（2.98:1） | 白字在 `#7C8CFF` 上不达 AA。 |
| 主题 | 锁深色单主题 + 高对比分支 | 深色为主，`[data-theme=light]` 只覆盖分类色板 | 见 §3.1 明暗裁决。 |
| 动效 | 零自动入场、零滚动 reveal | Modal / Toast 标准动画 | 官网无 Modal / Toast，reveal 与 <300ms 及反模板感冲突。 |

**明暗裁决：锁深色单主题，不提供 light / dark 切换。**
① 本次主要矛盾是修复品牌断裂，深色近黑是产品身份；② taste §4.11 Page Theme Lock 允许页面级锁单一主题，§8.C 明确「unless the brand insists on one mode」；③ `tokens.css` 的 `[data-theme='light']`（约 556 行）只覆盖 12 个 `--mc-cat-*` 分类色，背景 / 文本 token 未变，产品本身并无完整浅色主题，官网做浅色会重新制造断裂；④ 用户从未要求切换；⑤ 避免切换器变成又一个 AI 模板件。
落地：全页 ONE theme，区块只用同族深浅微差，绝不出现浅色区块。

**高对比度分支**：`html[data-contrast='high']` 与 `@media (prefers-contrast: more)` 双触发，覆盖 `--mc-text-primary:#F7F9FE` / `--mc-text-secondary:#C6CDDD` / `--mc-text-tertiary:#A8B0C0` / `--mc-border-subtle:#4A5164` / `--mc-border-strong:#6A7288`。`@media (prefers-reduced-transparency: reduce)` 下半透明回退实色（官网本就无半透明材质，此条为兜底）。

## 4. 布局系统

**网格策略**：全站 12 列定栅格；每个区块只用一种布局族，且每种布局族全站最多出现 1 次（taste §4.7 Section-Layout-Repetition Ban）。11 区块分配 10 个不同族：N 单行导航 / A 7:5 非对称 + 占位框 bleed / B 不等宽水平轨道 / C 左 sticky 标题 + 右行列表 / D 全宽大图 + 图下双列说明 / E 5:7 文字 + 局部图 / F 格式行列表 + mono 文本块 / G 提升底色 + 图标行 / H 原生 details 单列 / I 5:7 主 CTA + 平台行 / J 3 区页脚。无 zigzag 连续重复、无 3 列等宽卡、无 bento 空单元。

**非对称实现（3 个手法，均属 taste §7 的 4-7 Offset 档）**：① Hero `7fr:5fr` 左大右小（L1 v2 基因）；② Hero 右列占位框 `transform: translateY(32px)` 纵向错位 + `margin-right:-48px` 向右 bleed（仅 ≥1200px）；③ 相邻区块交替 7:5 / 5:7 / 4:8 列比，H2 一律左对齐、不居中。

**垂直节奏**：区块序列底色 `#0A0B0F → #0D0F15 → #101218 → #0A0B0F → #0D0F15 → #101218 → #151821 → #0A0B0F → #0D0F15 → #0A0B0F`，每节 `border-top: 1px solid #1A1D26`（Nav 与 Hero 之间不加，首屏无缝），靠同族深浅微差 + 发丝而非大留白分段。区块内 title → body 间距 16px，title → 内容 48-56px，行 `padding-block: 20-28px`。

**响应式断点行为（重点修复 ≤768px 无导航的 Critical 缺陷）**

- `≥1024px`：`header` 单行 `height:64px`，flex 三段（logo / 链接 / CTA），`position:sticky; top:0`。

## 6. 动效规范

### 6.1 频率门控表

| 元素 | 频率 | 决策 | 具体值 |
|---|---|---|---|
| 键盘 / 锚点跳转 | 高频 | **零动画** | `scroll-behavior:smooth` 仅 no-preference；reduce 下 `auto` |
| nav / 文字链 hover | 数十次/天 | 仅颜色 | `transition: color 100ms ease-out` |
| 主按钮 hover | 数十次/天 | 仅背景色 | `background-color 100ms ease-out` |
| 所有可按压元素 `:active` | 数十次/天 | 微缩反馈 | `transform:scale(0.97)`, `transform 160ms ease-out` |
| 特性行 / 平台行 hover | 偶尔 | 仅背景色 | `background-color 100ms ease-out` |
| FAQ 展开 | 偶尔 | **零动画**（原生瞬时） | `0ms` |
| 首屏占位框入场 | 1 次/会话 | 可选，建议省略 | `opacity 120ms ease-out`（若启用，无 transform） |
| 滚动 reveal / 交错入场 / 视差 / marquee / 无限脉冲 | 装饰 | **全部删除** | 无 |

### 6.2 时长与缓动

`--mc-dur-micro 100ms`（颜色 / hover）、`--mc-dur-fast 180ms`（官网用 160ms 做按压，取 emil 的 100-160ms 区间）、`--mc-ease-out: cubic-bezier(0.23, 1, 0.32, 1)`（唯一曲线）。禁 ease-in、禁 `transition: all`、禁 UI 时长 >300ms、禁 `scale(0)` 入场、禁 keyframes 用于可快速重复触发的元素。

颜色类过渡（`color` / `background-color` / `border-color`）属 paint 但不触发 layout，允许且必要；禁 `width` / `height` / `margin` / `padding` / `top` / `left` / `clip-path` 动画。`will-change` 不启用。

### 6.3 滚动显现取舍：不保留 reveal

① taste §5.C 的 600ms `y:24` 交错入场与 §18 §11「<300ms」硬冲突；② review-animations 标准 1 要求能一句话说明目的，reveal 只能答「hierarchy / storytelling」，而滚动淡入正是最典型的模板 signature；③ animate RECIPES 明确「Marketing surfaces only」，本官网定位是工具的产品页而非作品集；④ dial 2 属 Static 档，删除后声明与实现一致；⑤ 删除后零 IntersectionObserver、零 scroll listener、零动画库。

### 6.4 reduced-motion / reduced-transparency

```
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important; }
  html { scroll-behavior: auto; }
}
@media (prefers-reduced-transparency: reduce) { /* 官网无半透明材质；兜底：rgba 底回退实色 */ }
@media (prefers-contrast: more) { /* 见 §3.1 高对比分支 */ }
```

保留 opacity / color 变化助理解，移除位移与形变；官网本就无位移入场，reduce 下页面与默认态视觉几乎一致（刻意目标，不是漏做）。

### 6.5 动效十条标准自检

| # | 标准 | 状态 |
|---|---|---|
| 1 | Justified motion | 仅按压反馈 / hover 色变 / 当前导航指示，零装饰动画。通过 |
| 2 | Frequency-appropriate | 见门控表；键盘 / 锚点跳转零动画。通过 |
| 3 | Responsive easing | 唯一曲线 `cubic-bezier(0.23,1,0.32,1)`；零 ease-in。通过 |
| 4 | Sub-300ms UI | 最长 160ms，其余 100ms。通过 |
| 5 | Origin & physical correctness | 无 popover / dropdown / modal；按压 `scale(0.97)` 而非 `scale(0)`。通过 |
| 6 | Interruptibility | 全部 CSS transition，零 keyframes、零 JS 动画。通过 |
| 7 | GPU-only properties | transform / opacity / 颜色；零 layout 属性。通过 |
| 8 | Accessibility | reduce 全量守卫；hover 包 `(hover:hover) and (pointer:fine)`。通过 |
| 9 | Asymmetric enter/exit | 无 enter/exit 配对动画；不适用，无违规 |
| 10 | Cohesion | 全站 100/160ms + 单一曲线 + 零装饰，匹配 IDE 工具「crisp and fast」人格。通过 |

## 11. 素材策略

### 11.1 现有素材处置

`screenshots/` 四个文件实为 **2 张唯一图**（`welcome.png` = `editor.png`，`canvas.png` = `dashboard.png`）；`splash-shots/` 是启动画面帧，不进官网（启动动画帧不是产品功能证据）。

- **仪表盘 KPI 图（welcome / editor）：整张弃用**。① 画面是 4 个统计卡（`128,430` / `23 天` / `256` / `42`）+ 蓝色柱状图 + 标签分布条，正是用户在 DesignBrief 里多轮否掉的「一眼企业后台 / B 端控制台」范式；② 含多个假精确数字，命中 taste §4.9 / §9.D 与本项目禁令 #8。
- **白板 Canvas 图（canvas / dashboard）：界面框架可留，内容必须重采**。可留：左侧活动栏 + 文件树、顶部 `⌘K` 命令搜索、右侧属性 inspector、深色近黑底、发丝分隔、高密度（与用户认可的 VS Code 式活动栏 / IDE 感 / 键盘优先方向一致）。必须重采：① 便签文字是内部设计备注，不可对外；② 右侧属性面板颜色点含紫 / 粉，与 §18 §4.3 去紫纪律有轻微冲突；③ 整体是过程稿，非发布态。
