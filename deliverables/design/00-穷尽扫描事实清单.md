## 2. 产品本体事实

### 2.1 定位与身份

- **一句话定位**：local-first Markdown 知识库，把孤立笔记连成网络，白板作为思考画布，一键博客发布。
- **品牌释义**：`MarkCraft = Markdown + Craft`，「雕琢你的笔记」。
- **中文 tagline**：现代化 Markdown 编辑器 · 个人知识工坊 · 博客生成器。
- **版本**：`1.0.0`，MIT 许可，Copyright © 2026 MarkCraft。
- **产品形态**：Electron 44 桌面端是**唯一**产品形态，无 Web / PWA 可用形态。

### 2.2 技术栈（`package.json` / `README.en.md`）

| 层 | 技术 |
|---|---|
| 桌面运行时 | Electron 44（ESM main + CJS preload，`contextIsolation`，`nodeIntegration: false`） |
| UI | React 18.2 + TypeScript 5.2 |
| 构建 | Vite 5（renderer）+ esbuild（main/preload）+ electron-builder（NSIS / Portable） |
| 编辑器 | Tiptap 3.24（WYSIWYG）+ CodeMirror 6（源码），HTML↔Markdown 往返，**Markdown 是唯一真相源** |
| 白板 | Excalidraw 0.17 + 自建 `CanvasEngine` 兼容层 |
| Markdown | marked 14 + DOMPurify + morphdom；KaTeX + Mermaid |
| 检索 | 本地 384 维 hash-bag 向量引擎（无 IDF），`TfidfEngine`；**无 AI / 无 LLM** |
| 测试 | Vitest + Testing Library；194 测试文件 / 2258 用例（2 skipped）全绿 |

### 2.3 真实功能清单

- **编辑**：双引擎（WYSIWYG / 源码）、Front Matter、语法检查、大纲导航、数学公式与图表。
- **知识链接**：WikiLink、反向链接、未链接提及、块引用 `((id))`、嵌套标签 `#parent/child`、MOC 生成。
- **知识图谱**：**SVG 2D，4 种布局**（力导向 / 同心圆 / 树 / 网格），度数统计、BFS 邻域展开、快照导出。
- **Canvas v2 白板**：Excalidraw + 自建引擎，**8 种卡片类型**，思维导图 / 看板 / 时间线视图。
- **知识库**：多知识库、**7 个标签页**、4 维健康度评分、**本地统计检索**（关键词重叠段落选择 + 词频摘句）、知识库模板。
- **博客工坊**：**63 套预设主题**、**12 种导出格式**；真实部署适配器 GitHub / Gitee / Vercel / Cloudflare / Netlify；格式型发布 微信 / Substack / MDX / Hugo / Astro。
- **导入**：`.md / .txt / .docx / .html` → 统一高质量 GFM（表格已启用）。
- **本地优先**：无后端；设置在 `localStorage`，文件树 / 知识库 / 白板 / 版本历史以 JSON 存于 `%APPDATA%/MarkCraft/storage/`。
- **i18n**：完整中英双语 UI。
- **安全加固（2026-11）**：文件路径白名单 + 原子写、SSRF 防护（协议白名单 / 私网段 / DNS rebinding / 逐跳重定向校验）、导航与 webview 防御、iframe sandbox 无 `allow-same-origin`、导出 URL 白名单。
- **输入性能**：WYSIWYG 序列化 150ms 防抖 + 8 个显式 flush 点；lint 每次停顿一次；math 块提取 O(n)。

### 2.4 明确的能力边界（官网文案的红线）

来源 `README.en.md` § Known Limitations：

- **没有 AI / LLM 功能**。知识库「问答」与「相似检索」是本地统计检索，反映关键词分布而非语义。OpenAI 兼容 `RemoteEngine` 是**死代码**：`getAiService()` 从不传设置，`setAiService()` 从不被调用，无配置 UI。
- 知识图谱是 **2D SVG 4 布局**；早期设计文档提到的 **3D 球体、PageRank / 中介中心性、社区聚类从未实现**。
- PDF 导出依赖 `html2pdf.js`，复杂版式分页可能不完美。
- Windows 安装包可能以 `asar=false` 构建（Defender 实时扫描导致 electron-builder `unlink` EBUSY），功能等价。
- 大图（>500 节点）在低端硬件偏慢，尚无 LOD / 视口裁剪 / 空间索引。

### 2.5 下载与分发（真实约束）

- Windows x64：`MarkCraft-Setup-*.exe`（NSIS 安装版）与 `MarkCraft-Portable-*.exe`（免安装版）。
- 单个 exe 约 **201 MB**（官网 `downloadConfig.ts` 记 `210268563` 字节）。
- Gitee 免费版单文件 **100 MB** 限制，安装包**分卷托管在独立仓库**：`https://gitee.com/James-fake/markcraftxiazaicangdianhua`，`git clone` 后运行合并脚本还原，**无直链**。
- `package.json` 的 `build` 段另有 `mac`（dmg / zip）与 `linux`（AppImage）目标配置，README 也写了三平台安装说明；但实际发布与下载说明以 Windows 为主，**不应宣称 Mac / Linux 已发布**。

### 2.6 隐私与联网（官网文案的第二条红线）

来源 `docs/PRIVACY_POLICY_zh.md` 与源码：

- 笔记全部存本机，**无云端账号体系、无云同步**；笔记正文 / 标题 / 文件名 / 路径永不进入统计管线。
- **匿名使用统计默认关闭（opt-in）**：首次运行弹窗询问，勾选「我同意」后才启用，可在「设置 → 隐私」随时关闭。
- 同意后通过 **HTTPS** 批量防抖上报到部署方自建的隐私友好分析服务（Umami / Plausible / PostHog 类）；仅收集安装 ID（本地随机 UUID）、应用版本 / OS / 界面语言、功能使用次数与停留时长、崩溃**类名**（截断，不含消息与堆栈）、每日心跳。
- `src/features/telemetry/transport.ts:29` 使用 `fetch` 上报，关闭时 `sendBeacon` 尽力送达。
- `src/services/import/externalImporter.ts:236` 使用 `platform.net.fetch` 抓取用户指定的外部 URL（带 SSRF 防护）。
- 博客发布到 GitHub / Gitee / Vercel / Cloudflare / Netlify **必然联网**。

**结论**：官网「不发起任何联网请求」「当前版本没有任何需要联网的功能」均为过度承诺，与源码不符。
