数据归属与联网边界

没有云端账号，也没有云同步。存储位置、联网范围与统计开关都可以查证。

正文是你自己磁盘上的 .md 文件

选一个文件夹作为 Vault，内容以真实文件存在那里。应用状态（目录结构、知识库、白板、版本历史）以 JSON 存于本机应用数据目录，设置与主题存于 localStorage。

哪些功能会联网

博客发布与部署、导入外部 URL、上传到你自己配置的图床，以及你主动开启的匿名使用统计。编辑、双向链接、双链图谱与知识库检索都在本机完成。

匿名使用统计默认关闭

需你主动同意后才启用，同意后经 HTTPS 上报到自建的隐私友好分析服务，仅含安装 ID、应用版本、系统、语言、功能使用次数与停留时长、崩溃类名、每日心跳，不含正文、标题、文件名、路径或 IP。随时可关，关闭即停发并清空缓冲。

常见问题与已知边界

内容存在哪里？

选一个文件夹作为 Vault，正文以真实 .md 文件存在那里，任何编辑器都能打开。目录结构、知识库与版本历史以 JSON 存于本机应用数据目录，设置存 localStorage。

需要联网吗？

不用。编辑、双向链接、双链图谱与检索都在本机完成。会联网的只有博客发布、导入外部 URL、图床上传与你主动开启的匿名使用统计。

数据会被上传到你们的服务器吗？

正文不会离开你的设备，没有云端账号也没有云同步。匿名使用统计默认关闭，需你主动同意后才经 HTTPS 上报，随时可关。上报内容不含正文、标题、文件名、路径或 IP。

能用网盘同步吗？

可以。Vault 就是一个普通文件夹，用网盘、同步盘或 Git 同步它即可。应用自身状态存于本机应用数据目录，不在这个文件夹里。

可以导出成什么格式？

HTML、PDF、EPUB、Word、Markdown、LaTeX、reStructuredText、MediaWiki、OPML、Plain Text、PNG、JPEG，共 12 种。另有含全部文件与图片的 ZIP 整库备份。

支持哪些系统？

当前提供 Windows x64 的安装版与免安装版。其它平台尚未正式发布，发布前不会在官网宣传为已支持。

为什么是分卷，不是直接下载？

Gitee 免费版单文件限 100MB，单个 exe 约 201MB，无法整体托管，故以分卷存在独立安装包仓库。没有文件直链，clone 后运行合并脚本还原。

有哪些已知限制？

没有 AI 或大模型功能，知识库问答是本地统计检索。双链图谱是 SVG 2D 四布局，3D 球体与 PageRank 从未实现。PDF 复杂版式分页可能不完美，超过 500 节点的图谱在低端机可能偏慢。

获取安装包

版本以安装包仓库为准。安装包以分卷形式托管，clone 后运行仓库内合并脚本还原为完整 exe。
