### 2.1 采集规范

- 窗口固定逻辑 1600×1000（或 1200×900），导出 2x PNG-24。
- **深色主题**；系统桌面、其他应用、任务栏不入镜。
- 所有界面文字为已发布的最终文案；无调试信息、无设计备注、无假精确数字。
- 窗口 chrome 保留（真截图自带），官网**不再叠加** faux-OS 三色圆点或假标题栏。
- 统一语义化文件名：`editor-main@2x.png` / `graph-2d@2x.png` / `command-palette@2x.png` / `canvas-clean@2x.png`。
- 交付时同时提供 `width` / `height` 数值，供 HTML 预留 CLS 空间。
- 提供对应 `alt` 描述（描述真实界面内容，禁 `alt=""` / `alt="image"` 用于有意义图片）。

### 2.2 截图在页面中的渲染规格

见 `02-设计规范.md` §5.3：`<figure>` + `<img>`；容器 `background:#0A0B0F; border:1px solid #262B3B; border-radius:12px; box-shadow:var(--mc-shadow-panel); overflow:hidden;`；`<figcaption>` 在图下方外部，mono 12px；不可点则 `cursor:default` 无 onClick。

## 6. 回滚预案（上线阶段用）

官网是纯静态单页、无后端、无数据库，回滚成本低：

1. 保留改版前提交 `1970ea8`（master），改版以新提交推进，不覆盖历史。
2. Gitee Pages 若支持版本回退，直接切回上一版构建产物；否则 `git revert` 改版提交后重新构建。
3. 上线首日重点监控：SEO 摘要是否仍缓存旧的 3D / AI 文案、9 个锚点深链是否可达、移动端两行导航是否溢出、外链 `target/rel` 是否生效。
4. 若发现事实类错误，优先只改文案（配置驱动，改动面小），不回滚视觉。
